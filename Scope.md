Lets start with  Program Scope 

Scope = What you are allowed to test

This section tells you which assets the company allows you to attack and ofcourse you can attack out-of-scope targets also the only down side is that you will be marked as a red flag 

The Scope assets can include : 
1. Domains
2. Subdomains
3. Mobile apps
4. APIs
5. Cloud infrastructure
6. specific products

Types of scope : 
1. wildcard scope
2. Specific scope
3. Asset Type scope
